Never run Python training or smoke-test commands via background task management (manage_task) in this project. Always run in the foreground with the -u flag, capture full stdout and stderr, and apply an explicit timeout. If a command produces no new output for 30 seconds, treat it as hung, report the last known stage, and stop — do not wait indefinitely or retry silently. DataLoader num_workers must be 0 for any smoke-test invocation, hardcoded in Python, not read from config alone.
