# Post-Hoc Logit Adjustment on Exp-2c (PanDerm Uniform Control Arm)

## 1. Methodology

- **Adjustment Formula**: $\hat{y} = \arg\max_k (\log p_k - \tau \cdot \log \pi_k)$
- **Priors**: Computed on MILK10k dermoscopic training split ($N = 3,668$):
  - `AKIEC     `: N =  202 (pi = 0.05507, log(pi) = -2.8991)
  - `BCC       `: N = 1757 (pi = 0.47901, log(pi) = -0.7360)
  - `BEN_OTH   `: N =   27 (pi = 0.00736, log(pi) = -4.9116)
  - `BKL       `: N =  385 (pi = 0.10496, log(pi) = -2.2542)
  - `DF        `: N =   39 (pi = 0.01063, log(pi) = -4.5438)
  - `INF       `: N =   38 (pi = 0.01036, log(pi) = -4.5698)
  - `MAL_OTH   `: N =    6 (pi = 0.00164, log(pi) = -6.4156)
  - `MEL       `: N =  325 (pi = 0.08860, log(pi) = -2.4236)
  - `NV        `: N =  521 (pi = 0.14204, log(pi) = -1.9517)
  - `SCCKA     `: N =  332 (pi = 0.09051, log(pi) = -2.4023)
  - `VASC      `: N =   36 (pi = 0.00981, log(pi) = -4.6239)

- **Hyperparameter Tuning**: $\tau \in [0.00, 1.00]$ in increments of $0.05$ evaluated **strictly on the validation split** ($N = 786$).
- **Selection Rule**: $\tau^*$ selected per seed solely by validation Macro-F1.
- **Test Evaluation**: Chosen $\tau^*$ applied exactly once to the held-out test split ($N = 786$). No test labels used during selection.
