# Scripts (`scripts/`)

This directory contains command-line entry points and automation scripts for training, evaluation, data preparation, and export.

## Planned Scripts (Phase 1+)

- `train.py`: Main CLI training script accepting `--config <path>`.
- `evaluate.py`: Standalone evaluation script for test sets and subgroup fairness metrics.
- `download_weights.py`: Automation script to fetch PanDerm / DermFM-Zero pretrained weights from Hugging Face / Google Drive.
